# supabased.dev

The website for [supabased](https://github.com/m2ximus/supabased), a CLI that
connects the Supabase CLI to several Supabase accounts at once.

A single static page in `site/`, deployed to <https://www.supabased.dev> by
Vercel (`vercel.json` sets `site` as the output directory). No build step.

Preview locally:

```sh
python3 -m http.server -d site 8000
```
